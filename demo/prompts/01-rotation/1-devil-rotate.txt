Outage 1, a rotation nobody picked up. Rotate the shop's API token on all four workload clusters (staging, prod-eu, prod-us-1, prod-us-2) the way a security team's scheduled rotation or an external secret store does it: in each cluster, replace the value of key 'token' in Secret 'shop-token', namespace 'shop', with a new random value (for example from 'openssl rand -hex 16'), directly in the cluster. Do not print the token. Do not restart anything, and do nothing else.
