# Approval request for the approver: staging release of `chaos-shop-base/web-reload-on-token-rotation`

## What broke
`shop/web` is at 0 of 2 available on staging, prod-eu, prod-us-1 and prod-us-2. The api pods are healthy. Web's readiness probe fails with `HTTP Error 401: Unauthorized`.

## Cause
- The Secret `shop-token` was rotated by hand (`kubectl patch`) on all four clusters at 12:29:54–55Z. The Secret is not in ConfigHub.
- api reads the token from a mounted file on every request, so it picked up the new value.
- web reads it once, from the environment, at start, so it still sends the old token and api refuses it.
- Reloader runs in every cluster with default settings, so it only restarts workloads that carry its annotation. Web had none.

One unit, `shop` in `chaos-shop-base`, Deployment `shop/web` only (plus a comment line at the top of the unit):

- **Reloader annotation:** this is the prevention. Any later change to `shop-token` makes Reloader roll web.
